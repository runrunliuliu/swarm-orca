# Sparse 任务工作区（任务 sparse 契约）文档目录

本目录只放“任务 sparse 工作区”这一个子系统的文档：契约、开发计划、创建失败对账手册与实施前历史提案。
任务与工作区的通用模型（理念、对象、判据、跨 Project 与跨入口规则）不在本目录，仍在
[以任务为中心的工作区设计](../task-workspaces.md)。

本文只做索引与边界声明，不复述状态与契约正文。**不构成**实现、部署、重启、创建 worktree
或启动 Agent 的授权。

## 目录内容约定

- **契约**（`m0-contract.md`、`m3-start-gate.md`、`m5-min-contract.md`）只写“必须怎样”，
  各自带“本轮测试证据”和“已知缺口”，不写操作步骤。
- **开发计划**记录阶段拆分与交付状态，不重复测试证据（证据在契约内，避免两处过期）。
- **对账手册**只写观测与判定；不出现可自动执行的清理、重试或重建步骤。
- **历史**放实施前提案；保留原始取舍理由，但与被取代的正文一样不再代表当前接口。

## 入口与边界（一句话版）

只有 `orca worktree create --sparse-task-dir … --setup skip` 会构造任务 sparse 请求；桌面 UI、移动端与
`orchestration worker-start` 仍只传 cone（legacy sparse），建出的工作区没有 pin、回执与绑定，
不受启动门禁保护。SSH 上的任务 sparse 创建被明确拒绝，探针未接入前保持 fail-closed。
cone 是检出范围，不是写权限、沙箱或授权边界。

具体入口、参数与判定条件以各契约和[任务工作区设计](../task-workspaces.md) 为准，本目录不复制。
