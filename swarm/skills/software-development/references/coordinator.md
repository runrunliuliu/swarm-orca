# Operator and Coordinator

Freeze the original objective, requirements, authority sources and independently reviewed
scope before startup. Record repository/worktree, branch and base commit plus every visible
tracked and untracked file. Archive initial bytes and tracked dirty diffs. Initial dirty files
remain externally owned unless overlap is explicitly approved. Exclusions are audit coverage
gaps, never permission to write there; review Git metadata and excluded paths separately.

Use the schema's startup `domain_binding`, prepare input version 2 and continuation version 2.
The startup identity includes this binding; removing it or mixing RSI authority fields is invalid.
Keep the shared acceptance envelope unchanged. Include the domain selection, role pins and this
reference in the original pinned handoff; the generic historical bootstrap prompt is not a
software evidence schema. Use the software checker, not RSI authorized-progress commands.

Assign one writer per file, bind Tasks and Dispatches to requirements, and keep independent
review responsibility distinct from implementation. Native capacity/dependency checks and the
approved `max_workers` still govern dispatch. Do not introduce another scheduling state machine.

Publish a current-turn source and checker receipt, then use existing prepare / workflow /
turn-end / scheduler commands. Early actionable checkpoints need no final test/review evidence.
Waiting paths need readable linked dependency records, not speculative waiting. Failed tests,
review findings and unknown operations remain unresolved work. New bytes invalidate previous
snapshot evidence. Preserve rejected reviews and link the later re-review to every resolved rejection.

Before marking a requirement met, audit real logs and native object records independently of
the declarations under test. Verify reviewer identity, tested/reviewed snapshot, coverage and
rework. Finish via acceptance review and the existing lifecycle, reporting skipped tests and
unknown usage explicitly. Offline checks never prove automatic live continuation.
